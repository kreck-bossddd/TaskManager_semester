# TaskManager_semester

**TaskManager** — учебный проект для управления задачами, созданный в рамках изучения разработки программных продуктов.

## 🎯 Цель проекта

Разработка простой системы, позволяющей создавать, просматривать, искать, изменять и удалять задачи.

## 📌 Основные возможности

1. Создание задач.
2. Просмотр списка задач.
3. Поиск задач по названию.
   - Поиск по части названия.
   - Поиск без учёта регистра букв.
4. Изменение статуса задачи.
5. Удаление задач.
6. Установка приоритета задачи.

## 💻 Используемые технологии

- **Python** — язык программирования.
- *Git* — система контроля версий.
- **GitHub** — платформа для хранения и совместной разработки проектов.
